# Magic Ball

A simple Python console program inspired by the Magic 8-Ball. The user asks a question, and the program randomly selects one of several possible answers.

## Features

- Accepts a question from the user
- Randomly selects an answer
- Provides positive, negative, and uncertain responses
- Includes 20 possible answers

## Technologies

- Python 3

## How to Run

```bash
python magical_ball.py
```
